# Правила проекта

## Общие правила

- Объясняй изменения на русском языке.
- Перед крупными изменениями сначала составляй план.
- Не меняй несвязанные файлы.
- После изменений запускай проверку проекта.
- Не переписывай весь проект без необходимости.

## Контент

- Не придумывай цены, отзывы, сертификаты и факты об онлайн-школе.
- Недостающие данные помечай как TODO.
- Не используй реальные персональные данные в тестовой форме.

## Дизайн

- Используй адаптивную mobile-first вёрстку.
- Сохраняй единый стиль кнопок и карточек.
- Делай основной призыв к действию заметным.
- Не добавляй чрезмерные анимации.

## Доступность

- Используй семантические HTML-теги.
- Добавляй alt-тексты к изображениям.
- Делай видимые focus-состояния.
- Проверяй клавиатурную навигацию.
- Не полагайся только на цвет для передачи смысла.

## Безопасность

- Не вставляй секретные ключи в клиентский код.
- Не добавляй файлы .env в Git.
- Не используй реальные данные учеников и клиентов.
